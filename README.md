## Featured project · 만들고 있는 프로젝트

### [Font Pocket](https://github.com/tae0604/font-pocket)

**Download, install and manage fonts on Windows.**  
**Windows에서 여러 폰트를 한 번에 다운로드하고 설치하는 도구입니다.**

Every Windows reset or new computer meant downloading and unpacking my Figma fonts all over again. Font Pocket grew out of wanting to do that in one go.

Windows를 초기화하거나 컴퓨터를 새로 살 때마다 Figma에서 쓸 폰트를 하나씩 다운로드하고, 압축을 풀고, 설치하기가 번거로웠습니다. 그 과정을 한 번에 처리하고 싶어 만들기 시작했습니다.

- **Import together** — Add Noonnu links, ZIP archives and individual font files to one queue.  
  **한 대기열에 모으기** — 눈누 링크, ZIP, 단일 폰트 파일을 함께 추가합니다.
- **Choose what to install** — Select the font files and formats you need.  
  **필요한 것만 설치** — 원하는 폰트 파일과 형식을 선택합니다.
- **Preview and manage** — Compare fonts, review duplicates, and back up your collection.  
  **미리 보고 관리** — 폰트를 비교하고, 중복을 확인하고, 백업합니다.
